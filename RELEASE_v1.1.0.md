# v1.1.0 - Stable Release

## ✨ Features dari v2.0.0 Dev Branch

### 🎨 UI/UX Improvements
- Kategori management dengan inline editing
- Filter periode transaksi (today, week, month, year, custom)
- Alert modal untuk konfirmasi aksi berbahaya
- Dashboard masonry layout

### 🏦 Account & Category Management
- CRUD kategori via API dan web
- Archive/unarchive account
- Kategori colors dan customization

### 🤖 Telegram Bot Enhanced
- CRUD kategori via bot
- Query info lengkap
- Natural language processing lebih baik

### 📊 Analytics
- Budget progress tracking
- Cashflow visualization 6 bulan
- Category spending analysis
- Savings rate calculation

### 🔒 Security & Stability
- Login rate limiting
- Input validation improvements
- Better error handling
- Database migration on startup

## 📦 Installation

```bash
git clone https://github.com/Heda312/expenses-tracker.git
cd expenses-tracker
git checkout v1.1.0
docker compose up -d
```

git pull
